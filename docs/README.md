# Vesper Documentation

Documentation for the Vesper programming language.

## Structure

- `index.md` — documentation home
- `getting-started.md` — installation and basic usage
- `language/` — language features and syntax
- `reference/` — compact language reference
- `tools/` — CLI and formatter
- `contributing.md` — development information

The documentation is written for Jekyll and uses front matter compatible with Just the Docs-style navigation.

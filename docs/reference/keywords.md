# Keywords

| Keyword | Purpose |
|---|---|
| `let` | Declare an immutable variable |
| `mut` | Declare a mutable variable |
| `fn` | Declare a function |
| `if` | Conditional execution |
| `else` | Alternative conditional branch |
| `while` | While loop |
| `return` | Return a value from a function |
| `import` | Import a module |
| `as` | Assign an alias to an imported module |
| `export` | Mark a function for export |
| `extern` | Declare an external function |
| `void` | Void return type |
| `break` | Reserved loop-control keyword |
| `true` | Boolean literal |
| `false` | Boolean literal |
| `int` | Integer type |
| `float` | Floating-point type |
| `bool` | Boolean type |
| `string` | String type |
| `print` | Built-in output operation |
| `input` | Built-in input operation |

The keyword list should be updated whenever the lexer adds or removes reserved words.

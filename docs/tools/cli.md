# Command Line

The Vesper executable is invoked with a `.vsp` source file.

```text
vesper <file.vsp>
```

## Help

```text
vesper --help
vesper -h
```

## Version

```text
vesper --version
vesper -v
```

The current version is:

```text
0.1.0
```
